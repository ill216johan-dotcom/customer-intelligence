## Бизнес-требования

### Основные функции

1. **Конспектирование созвонов (Jitsi)**
   - Автоматическая запись через Jibri
   - Speech-to-Text через Whisper
   - Диаризация спикеров
   - AI-саммари через GLM-4

2. **История переписок (Telegram)**
   - Ежедневная выгрузка из чатов менеджеров
   - Саммаризация диалогов
   - Привязка к карточке клиента

3. **CRM данные (Bitrix24)**
   - Синхронизация контактов
   - История звонков (Мегафон)
   - Email переписка

4. **WMS интеграция**
   - История отгрузок
   - Алерты: много броней, потенциальный съезд

5. **RAG-чат**
   - Вопросы о клиенте в свободной форме
   - Поиск по всей истории взаимодействий

### Нефункциональные требования

- **Пользователи:** 15 человек
- **Клиенты:** ~100 ключевых (мониторинг)
- **Нагрузка:** 7-10 созвонов/день × 30-90 мин
- **Бюджет:** минимальный (~3000 руб/мес)

## Принятые решения (ADR)

### ADR-001: Whisper вместо Yandex SpeechKit
**Дата:** 2026-02-17
**Решение:** Использовать self-hosted Whisper
**Причина:** 10ч аудио/день × 22 дня = 220ч/мес → ~25,000 руб на Yandex vs 0 руб на Whisper
**Компромисс:** Требуется мощный сервер (16GB RAM)

### ADR-002: GLM-4 вместо Claude
**Дата:** 2026-02-17  
**Решение:** GLM-4 API для саммаризации
**Причина:** Бюджетные ограничения
**Компромисс:** Качество может быть чуть ниже, но достаточно для задачи

### ADR-003: Telethon для Telegram
**Дата:** 2026-02-17
**Решение:** Userbot через Telethon
**Причина:** Нужен доступ к личным чатам менеджеров
**Риск:** Возможен бан аккаунта при агрессивном использовании

### ADR-004: Customer Health Scoring Model
**Дата:** 2026-02-17
**Решение:** Комплексный Health Score из 5 компонентов (Engagement, Sentiment, Operations, Financial, Relationship)
**Причина:** Проактивное выявление рисков оттока (churn) до того, как клиент уйдёт
**Референс:** NotebookLM use case от Zvi Shapira + Gainsight/ChurnZero best practices

### ADR-005: Sentiment Analysis Pipeline
**Дата:** 2026-02-17
**Решение:** GLM-4 для анализа тональности + тренд-анализ
**Альтернативы рассмотрены:** VADER (слишком базовый), Transformers fine-tuned (требует данных)
**Причина:** GLM-4 уже используется в системе, русский язык поддерживается

### ADR-006: RFM-based Engagement Scoring
**Дата:** 2026-02-17
**Решение:** Recency-Frequency-Monetary модель адаптированная под фулфилмент
**Референс:** Kortix-AI/Suna implementation
**Компоненты:** R = давность контакта, F = частота коммуникаций, M = объём отгрузок
