# Customer Intelligence Platform — UI/UX Documentation

## Описание проекта

**Customer Intelligence Platform** — это система для управления отношениями с клиентами в fulfilment-бизнесе. Платформа агрегирует данные из различных источников (звонки, сообщения, заметки) и предоставляет AI-аналитику для принятия решений.

---

## Дизайн-система

### Цветовая палитра

Основана на стиле **Notion/Yonote** — минимализм, тёплые оттенки серого, отсутствие ярких акцентов.

```css
/* Backgrounds (тёплые серые) */
--background: #ffffff       /* Основной фон */
--bg-secondary: #F7F7F5     /* Сайдбар, вторичный фон */
--bg-tertiary: #EFEFEF      /* Hover states */

/* Text */
--text-primary: #37352F     /* Основной текст (почти чёрный) */
--text-secondary: #787774    /* Вторичный текст */
--text-tertiary: #9B9A97     /* Placeholder, disabled */

/* Borders */
--border: #E9E9E7            /* Тонкие границы */

/* Accent (используется редко) */
--accent-blue: #2383E2       /* Ссылки, фокус */
```

### Типографика

```css
/* Font: Inter / system-ui */
font-size-base: 14px
line-height: 1.5

/* Headings */
H1: 24px / 600 (font-semibold)
H2: 16px / 600
H3: 14px / 600 (label)

/* Body */
14px / 400 (regular)
13px / 400 (small)
12px / 400 (caption)
```

### Border Radius & Spacing

```css
/* Radius */
--radius-sm: 3px            /* Small elements */
--radius-md: 6px            /* Buttons, inputs */
--radius-lg: 8px            /* Cards */
--radius-xl: 12px           /* Large cards (редко) */

/* Spacing (4px scale) */
4px, 8px, 12px, 16px, 24px, 32px
```

### Тени

```css
/* Почти нет теней! Плоский дизайн */
--shadow-sm: 0 1px 2px rgba(0,0,0,0.04)   /* Только для layered elements */
--shadow-md: 0 4px 12px rgba(0,0,0,0.08)  /* Modals, dropdowns */
```

## Страницы

### 1. Главная (`/`)

**Назначение:** Обзор последних событий и рекомендуемых действий.

**Компоненты:**

#### Header
- Приветствие по времени суток ("Доброе утро/день/вечер")
- Кнопки: "Заметка" (primary) + "Загрузить" (secondary)

#### Search Bar
- Поиск по всем активностям

#### Drag & Drop зона
- При перетаскивании файла — полноэкранный оверлей
- Баннер с информацией о файле после перетаскивания
- Открывает диалог прикрепления к клиенту

#### Grid Layout (3 колонки)

**Левая часть (2 колонки):**
- Список последних активностей
- Карточки: звонки, сообщения, алерты, заметки
- Клик → детальная информация

**Правая часть (1 колонка):**
- Рекомендованные действия (алерты)
- Карточка "Инсайт дня" со статистикой

#### Активности

Типы активностей с цветовой кодировкой:

| Тип | Цвет | Иконка | Label |
|-----|------|--------|-------|
| Звонок | blue-50/80 | Phone | "Звонок" |
| Сообщение | emerald-50/80 | MessageSquare | "Сообщение" |
| Алерт | amber-50/80 | Bell | "Алерт" |
| Заметка | stone-100/80 | FileText | "Заметка" |

#### Фильтры
- "Мои клиенты" / "Все клиенты" (toggle)
- Поиск по имени или компании

```

│  📞 📧 💬                       │
```

### 3. Страница клиента (`/customers/[id]`)

**Назначение:** Детальная информация о клиенте + RAG-чат + База знаний.

#### Header
- Кнопка "← Клиенты"
- Аватар + Имя + Компания
- Кнопки: "Редактировать" + "Удалить"

#### Информация о клиенте
- Телефон, Email, Telegram
- "Работаем с" (дата начала сотрудничества)
- AI-резюме (если есть)

#### Tabs (underline variant)

| Tab | Содержимое |
|-----|------------|
| **Чат клиента** | AI-ассистент по конкретному клиенту |
| **База** | Поиск по данным клиента + статистика |
| **Звонки** | Список звонков с пагинацией |
| **Переписки** | Сообщения в мессенджерах |
| **Заметки** | Заметки по клиенту |

##### Чат клиента (RAG)
- Приветственное сообщение от AI
- История сообщений (user / assistant)
- Поле ввода с кнопкой отправки
- AI отвечает информацией о звонках, сообщениях, заметках клиента

##### База клиента
- Поиск по звонкам, сообщениям, заметкам
- Результаты с релевантностью
- Статистика: звонки, сообщения, заметки

## Взаимодействие данных

### Store Architecture

Все данные синхронизируются через **React Context** (`DataStoreProvider`).

**Данные сохраняются в localStorage:**
- `customer-intel-data` — все данные приложения

### Методы Store

| Метод | Описание |
|-------|----------|
| `customers` | Список клиентов |
| `addCustomer()` | Добавить клиента |
| `updateCustomer()` | Обновить клиента |
| `deleteCustomer()` | Удалить клиента |
| `activities` | Все активности |
| `addActivity()` | Добавить активность |
| `notes` | Заметки по клиентам |
| `addNote()` / `deleteNote()` | Управление заметками |
| `alerts` | Алерты |
| `markAlertRead()` / `resolveAlert()` | Управление алертами |
| `personalNotes` | Личные заметки |
| `addPersonalNote()` / `deletePersonalNote()` | Управление личными заметками |

### Потоки данных

```
┌─────────────┐     ┌─────────────┐
│   Главная   │────▶│    Store    │
│             │◀────│             │
└─────────────┘     └──────┬──────┘
                            │
        ┌───────────────────┼───────────────────┐
        ▼                   ▼                   ▼
┌─────────────┐    ┌─────────────┐    ┌─────────────┐
│   Клиенты   │    │   Заметки   │    │    Данные   │
│             │    │             │    │             │
│  └─[id]     │    └─────────────┘    └─────────────┘
│    │         │
│    ▼         │
│  Чат/База    │
└─────────────┘
```

**Примеры синхронизации:**

1. **Создание заметки на главной → отображение в Данных**
   - `addNote()` на главной
   - Автоматически появляется в `/data`
   - Появляется в заметках клиента `/customers/[id]`

2. **Добавление клиента → отображение везде**
   - `addCustomer()` в `/customers`
   - Клиент появляется в селектах на главной, в заметках

3. **Алерт → отметка как прочитанный**
   - Клик по алерту на главной
   - `markAlertRead()` в store
   - Алерт исчезает из рекомендованных действий

## Компоненты UI

### Button

```tsx
<Button variant="default" size="md">
  Основная кнопка
</Button>

<Button variant="outline" size="sm">
  Вторичная кнопка
</Button>
```

**Variants:** `default`, `outline`, `ghost`
**Sizes:** `sm`, `md`, `lg`

### Badge

```tsx
<Badge variant="secondary" size="sm">
  Label
</Badge>
```

**Variants:** `default`, `secondary`, `destructive`, `outline`
**Sizes:** `sm`, `md`

### Dialog

```tsx
<Dialog open={open} onOpenChange={setOpen}>
  <DialogContent>
    <DialogHeader>
      <DialogTitle>Заголовок</DialogTitle>
    </DialogHeader>
    {/* Content */}
    <DialogFooter>
      <Button>Отмена</Button>
      <Button>Сохранить</Button>
    </DialogFooter>
  </DialogContent>
</Dialog>
```

### Input

```tsx
<Input
  label="Поле"
  placeholder="Введите значение"
  value={value}
  onChange={setValue}
  error={error}
  leftIcon={<Search />}
/>
```

### Tabs

```tsx
<Tabs defaultValue="tab1">
  <TabsList variant="underline">
    <TabsTrigger value="tab1">Tab 1</TabsTrigger>
    <TabsTrigger value="tab2">Tab 2</TabsTrigger>
  </TabsList>
  <TabsContent value="tab1">...</TabsContent>
  <TabsContent value="tab2">...</TabsContent>
</Tabs>
```
